# 1번 담당 — DB · 서버 환경 · 회원 관리

## 담당 목표
Spring Boot와 Oracle의 공통 연결 환경을 마련하고, `MEMBER` 기반 회원 관리 기능을 구현합니다. **다른 팀원이 개발할 수 있는 공통 환경 제공**이 초기 핵심 업무입니다.

## 할 일 체크리스트
### 1. 공통 환경
- [ ] GitHub 프로젝트 개발 방식 및 폴더 구조 팀원과 합의
- [ ] Spring Boot(Java 17+) 프로젝트 생성, 필요한 의존성 확인
- [ ] 개발 서버 로컬 실행 확인(`localhost`)
- [ ] Oracle JDBC 연결 테스트 및 환경변수 구성
- [ ] 모든 팀원이 동일한 방식으로 앱을 실행할 수 있도록 README 작성
- [ ] Oracle 접속이 불가능한 팀원을 위한 테스트 DB/대체 연결 방식 논의
- [ ] `MEMBER`, `LANE`, `RESERVATION`, `RESERVATION_LANE`, `USAGE` 테이블과 PK·FK·CHECK 점검
- [ ] DB 변경이 필요하면 팀원과 합의 후 스키마 문서 갱신

### 2. 회원 기능
- [ ] 회원 목록 조회 및 이름/전화번호 검색
- [ ] 회원 상세 정보 조회
- [ ] 회원 등록(필수 필드 검증)
- [ ] 회원 정보 수정
- [ ] 특정 회원의 예약 이력 조회 (`MEMBER`↔`RESERVATION` JOIN)
- [ ] 회원별 예약 횟수 조회(4번 통계 담당과 연계)
- [ ] 예약 이력이 있는 회원의 삭제 정책 논의(FK 무결성 유지)

### 3. 공통 백엔드 지원
- [ ] 기본 Controller/Service/Repository 작성 방식 문서화
- [ ] 공통 오류 응답 및 예외 처리 방식 합의
- [ ] 날짜 입력/출력 형식 통일
- [ ] GitHub에 비밀번호를 올리지 않도록 설정 분리

## 담당 데이터
- 직접 관리: `MEMBER`
- 연관 조회: `RESERVATION`
- 공통 확인: 전체 5개 테이블 및 관계

## 화면 (예정)
- `/members` — 회원 목록/검색
- `/members/new` — 회원 등록
- `/members/{id}` — 회원 정보 및 예약 이력
- `/members/{id}/edit` — 회원 수정

URL은 팀 공통 규칙 확정 시 변경 가능.
