# 3번 담당 테스트 14건 (예제 소스에 작성됨)

## Java 통합 테스트 (11)
1. H2 데모 3/10/3/4/1건의 초기 데이터 및 조회 확인
2. 예약 1001의 레인 1번 이용 시작→종료, 예약 상태 동기화
3. 예약 1002의 레인 2·3번 별도 이용, 모두 끝나야 예약 완료
4. 중복 시작 차단
5. 배정되지 않은 레인 시작 차단
6. 이미 완료한 예약 시작 차단
7. 허용되지 않은 시설 상태 차단
8. 현재/미래 예약이 있는 레인 점검 전환 차단
9. 비어 있는 레인 점검 전환 허용
10. 점검중 레인에 가상 배정이 있더라도 시작 차단
11. 이미 완료된 이용의 중복 종료 차단

## 화면 요청 테스트 (3)
- GET `/lanes` → 정상
- GET `/lanes/1` → 정상
- GET `/usages` → 정상

## 실행
```powershell
mvn test
mvn spring-boot:run
```

`http://localhost:8080/lanes` 접속.

**테스트는 H2 데모 데이터베이스만 사용**하고 실제 개인 Oracle에 접속하지 않습니다. 이 문서는 테스트 코드 작성 현황을 나타내며, 개발 환경에서 Maven이 없어 아직 테스트 실행 성공은 확인하지 않았습니다.
